# MaxShop — лабораторная работа №7

Учебный адаптивный макет цифрового магазина для лабораторной работы «Макет пользовательского интерфейса». Исходные интерфейс, товары и три палитры сохранены.

- Репозиторий: https://github.com/fun21game21/maxshop-lab7-demo
- Сайт: https://fun21game21.github.io/maxshop-lab7-demo/

## Страницы и технологии

- `index.html` — главная, категории, поиск и каталог.
- `product.html` — карточка кита «Иммортал» для Minecraft / DexLand.
- `checkout.html` — корзина и пять шагов оформления.

HTML5, CSS3 (Grid, Flexbox, media queries, CSS-переменные), JavaScript без библиотек. `localStorage` сохраняет корзину, ник, шаг оформления, валюту и палитру. Сборка и серверная часть не нужны.

## Локальный запуск

Из папки репозитория выполните:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Для проверки префикса GitHub Pages запустите сервер из родительской папки и откройте http://localhost:8000/maxshop-lab7-demo/.

## Пользовательский сценарий

Главная → «Посмотреть каталог» → Minecraft / DexLand → Кит «Иммортал» → «Добавить в корзину» → «Оформить заказ» → ник пользователя → «Далее» → TON / USDT TON / USDT TRON → «Создать заказ и оплатить» → реквизиты → «Проверить оплату» → успешный результат → «Вернуться в магазин».

Количество меняется кнопками − / + (1–99). Точная учебная сумма зависит от количества. Ник обязателен. Повторное добавление товара начинает новый сценарий с корзины. После успешной оплаты переход из оформления в каталог или заказы автоматически очищает текущее оформление. Выбранная палитра и история заказов сохраняются.

## Тестовая оплата

**Не отправляйте деньги. Реальные платежи, кошельки, блокчейн и выдача товаров не подключены.**

TON / USDT TON / USDT TRON служат только для проверки интерфейса. Адреса `12345abcd`, `67890efgh`, `24680ijkl` недействительны, QR-макет декоративный. Кнопки копируют учебные значения; «проверка» — таймер на 1,1 секунды с успешным результатом. Суммы фиксированы для тестирования, не являются актуальными курсами и не обеспечивают уникальности настоящих платежей. Номер заказа и статус выдачи также являются макетом; история заказов хранится только в localStorage этого браузера и не синхронизируется между устройствами.

## Палитры

Вверху каждой страницы доступны «Ч/Б» (ахроматическая), «60/30/10» (хроматическая) и «Триада» (классическая триада). Выбор сохраняется между страницами и после перезагрузки.

## GitHub Pages

Публикация непосредственно из `main`, папка `/ (root)`, режим Deploy from a branch. Пользовательский GitHub Actions workflow не требуется. `.nojekyll` отключает обработку Jekyll. Все внутренние пути относительные и поддерживают префикс `/maxshop-lab7-demo/`.

Полный интерактивный сценарий реализован для кита «Иммортал»; остальные пять товаров сохраняют роль статичных карточек исходного макета.

## Заказы и навигация

Вкладка «Заказы» в шапке открывает `index.html#orders`: отдельную HTML-страницу добавлять не требуется. После успешной проверки сохраняются номер, дата, товар, количество, сумма, валюта, ник и статус заказа. История доступна после перезагрузки. После успешной оплаты кнопки «Вернуться в магазин» и «Мои заказы», а также переходы через шапку автоматически очищают текущее оформление, сохраняя историю заказов и палитру. Корзина при следующем открытии начинает оформление с первого шага; неоплаченный заказ сохраняет текущий шаг. При отсутствии заказов показана кнопка перехода в каталог. Логотип и название MaxShop на каждой странице ведут в `index.html#catalog`.
